## Retained automation

[`scripts/securewave_post_reboot_acceptance.py`](../../scripts/securewave_post_reboot_acceptance.py)
drives the installed GUI with AT-SPI. It retains helper runtime, the public
server parameters, routing/DNS/egress observations, and window screenshots in
a private evidence directory. It never saves generated passwords or bearer
tokens. Raw local evidence, application secure storage, network configuration,
and historical runtime artifacts are excluded from Git.

The lifecycle operation performs GUI Connect, a recent expected-peer
handshake, full-tunnel IPv4 route and changed egress checks, a complete 3 MiB
HTTPS download with independent RX/TX counter increases, GUI Disconnect,
Reconnect with the same checks, and a final GUI Disconnect. Each disconnect
checks removal of the interface and temporary config plus exact restoration
of baseline routes, rules, DNS, and public egress. These lifecycle checks are
prepared but **have not run in this checkpoint**. The harness does not verify
final production usage-ledger persistence; that remains a separate gate.

The local environment already provides Python 3, `pyatspi`, PyGObject/GDK 3,
X11 libraries, `curl`, `iproute2`, and `resolvectl`. It needs an unlocked
graphical session, the installed package, its running helper, and working
production connectivity. It does not build or modify product source.
