# SecureWave 1.0.0: saved monthly usage and compact layouts

Published **8 October 2026** with owner authorization. This replaces the previous
website installer while retaining application and Debian version **1.0.0**.
The owner confirmed the data usage gauge works correctly before requesting
this layout cleanup and installer publication.

## Included behavior

- Every new account is Free with an exact 5,000,000,000-byte monthly allowance.
- The live account usage bar, finalized session totals and pending report preview
  persist through disconnect, logout and repeat login.
- Settings shows account identity/type, VPN location/state, WireGuard, app version
  and monthly usage.
- Home uses the available width for the connection control and information;
  Settings groups account and VPN summaries. At normal text size, both pages fit
  1280×720, 900×600, 640×680 and 390×844 viewports without scrolling. Very small
  windows and enlarged accessibility text retain scrolling rather than clipping.
- The existing navy/cyan colours, fonts, circular control and truthful counters
  are preserved. No authentication, helper, reporter or tunnel behavior changed
  during this layout refinement.

See the [monthly accounting algorithm](../development/monthly-usage.md) and
[feature validation](../development/monthly-usage-validation-2026-10-08.md).
MARL/XGBoost remains optional backend routing in shadow mode; it does not
estimate, discount or modify billable bytes.
