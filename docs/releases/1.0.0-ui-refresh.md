# SecureWave 1.0.0 centered UI refresh

The application retains the centered authentication and connection layouts selected by the owner. The later two-column experiment is reverted; its presentation-only patch is preserved in `docs/archive/patches/securewave-ui-alternate-layout.patch`.

The UI uses the existing dark/cyan palette, locally bundled Space Grotesk and JetBrains Mono, circular connection control, integrated location/protocol/transfer region, keyboard focus, reduced motion and responsive stacking. Existing notices and counter availability remain visible.

`app.dart`, both services, native/helper integration, routing, DNS, backend, database, dependencies and packaging behavior are unchanged from the approved `05f0f40e32b9334b2edcb7db5b955ca03ab74697` baseline. The app version remains **1.0.0**.

The interlocking-wave icon is saved as a candidate SVG and eight PNG sizes under `securewave_app/assets/icons/linux/`. It is not referenced by the shipping Flutter assets or Linux desktop entry. The existing shipping icon remains unchanged pending explicit visual approval.

Presentation fixtures and goldens are visual tests only. They are not evidence of a live WireGuard tunnel. Publication evidence records the exact clean source SHA, package checksum and public serving separately; prior installed/reboot acceptance does not automatically apply to this build.
