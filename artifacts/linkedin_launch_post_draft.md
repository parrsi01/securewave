# LinkedIn Launch Post Draft

SecureWave is now preparing its Linux desktop free release candidate.

This first public v1 scope is intentionally focused: Linux desktop, with WireGuard as the primary VPN protocol. The current build is designed around a real Linux runtime path using `wg-quick`, authenticated profile delivery, usage accounting, reconnect handling, disconnect cleanup, and release artifact verification.

The free release candidate is for users who want to test SecureWave on Linux and help validate the core desktop VPN experience before broader platform and plan expansion.

What is available to test now:

- Linux desktop client release candidate.
- WireGuard-primary VPN connection flow.
- Account sign-in and authenticated profile retrieval.
- Usage visibility for the current free mode.
- Verified Linux release artifact path.

What is intentionally not being announced as public v1 support:

- Windows, macOS, iOS, and Android VPN runtime readiness.
- IKEv2 as a public release-visible protocol.
- OpenVPN beyond the already certified covered Linux runtime/helper dataplane path.
- Paid production billing as live today.

Premium features are planned, but the current public message is simple: SecureWave is available as a Linux desktop free release candidate first, and we are keeping the launch scope narrow so the claims match the evidence.

If you run Linux and want to test the early desktop release, SecureWave is ready for release-candidate feedback.
