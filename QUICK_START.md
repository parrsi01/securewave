# Quick Start

## Local Development

```bash
bash deploy.sh local
```

Open:
- `http://localhost:8000/home.html`
- `http://localhost:8000/api/docs`

## Production (Hetzner)

See `docs/HETZNER_RUNBOOK.md` for provisioning, bootstrap, and deploy steps.

Key defaults:
- Single server
- `cx33` server type
- SSH + WireGuard firewall only
