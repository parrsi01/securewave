Diagnostics

Run connection diagnostics inside the app.

Because the VPN tunnel runs on the device, tunnel, route, traffic, and protocol checks are performed from the app. The website helps you understand when to run them and what to do next.

Recommended workflow
  • Confirm your account and plan in the dashboard.
  • Open the SecureWave app and run diagnostics.
  • Retry from the current app build if a download update is available.
  • Use the support page if the issue persists after diagnostics.
