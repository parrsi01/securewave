# Research only

Beta 1 has no machine-learning runtime dependency. XGBoost may be evaluated
later as an asynchronous health observer; it must not authenticate users,
route traffic, or gate a tunnel. MARL remains offline research for a future
multi-server or reconnect experiment and is not part of the shipped app.

Research additions must stay outside the production API, Flutter client,
helper contract, and package dependency set until a separately accepted scope
defines them.
